# Sistema Integral de Gestion - Software FJ

## Descripcion

Este proyecto corresponde a un sistema integral orientado a objetos para gestionar clientes, servicios y reservas de la empresa Software FJ.
El sistema no utiliza bases de datos. Toda la informacion se gestiona mediante objetos, listas internas y archivo de logs.

## Funcionalidades

- Registro de clientes
- Validación de datos
- Registro de servicios
- Reserva de salas
- Alquiler de equipos
- Asesorias especializadas
- Creacion de reservas
- Confirmacion de reservas
- Cancelacion de reservas
- Procesamiento de costos
- Manejo avanzado de excepciones
- Registro de eventos y errores en logs

## Principios de programacion orientada a objetos aplicados

- Abstraccion
- Herencia
- Polimorfismo
- Encapsulacion
- Manejo de excepciones personalizadas
